# 2026-09-20

### 新增

- **Providers 新增内置预置渠道 CommandCode**：
  - 在渠道管理（Providers）的新建渠道预置列表 `PRESET_CHANNELS` 中集成 **CommandCode**（OpenAI 兼容端点 `https://api.commandcode.ai/provider/v1`）。
  - 支持在新建渠道弹窗中一键选择 CommandCode 预置 chip，自动填充协议类型（`openai`）、目标地址（`https://api.commandcode.ai/provider/v1`）及建议渠道名（`commandcode`），并锁定目标地址防误改。
  - 完全复用现有的 `PRESET_CHANNELS` 与上游模型同步机制，配置 API Key 后可直接拉取/同步 CommandCode 提供的模型列表（如 `meta/muse-spark-1.3-contributor`、`google/gemini-3.8-flash` 等）。
