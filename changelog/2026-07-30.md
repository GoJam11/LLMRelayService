# 2026-07-30

### 新增

- **Zero Data Retention (ZDR) 零数据保留功能**：新增账号级隐私开关，默认对所有账号/组织/API Key 开启。
  - 数据库新增 `consoleProviders.zdrCapable/noTrainingCapable/zdrOverride`、`modelAliases.zdrOverride`、
    `consoleRequests.zdrActive` 字段，以及 `zdrPrivilegedTokens`（一次性提权令牌）、`zdrAuditLog`
    （设置变更审计日志，仅记录操作元数据，绝不记录 prompt/completion 内容）两张新表（pg/sqlite 双方言迁移）。
  - `src/zdr-settings.ts`：全局 ZDR 开关（`gatewaySettings` key，5s TTL 缓存）与四级作用域（全局 / 模型组
    / guardrail（渠道） / 单次请求）「最严格优先」的有效值解析 `resolveEffectiveZdr`，单次请求的宽松覆盖
    永远无法削弱更严格的上层设置。
  - `src/zdr-privileged-token.ts`：关闭 ZDR 需要重新输入密码，换取 5 分钟有效期、一次性消费的提权令牌
    （`zdr.disable` purpose，SHA-256 哈希存储）。
  - `src/zdr-log-redaction.ts`：ZDR 生效时，在写入 `console-store.ts` 请求/响应快照前彻底剥离
    prompt/completion 原文、payload、headers，只保留请求 ID、时间戳、模型、渠道、token 用量、延迟、状态码、
    ZDR 标记等元数据。
  - `src/zdr-provider-filter.ts` + `src/zdr-runtime.ts`：ZDR 生效时只路由到已标记 `zdrCapable` 的渠道，
    接入 `src/index.ts` 的候选路由构建阶段，不改动既有路由/故障转移算法本身。
  - `src/zdr-audit.ts`：记录 ZDR 设置变更审计事件（操作、作用域、操作者 IP、时间），不记录任何内容。
  - 控制台 API：`GET/PATCH /__console/api/settings/zdr`、`POST /__console/api/settings/zdr/reauth`
    （密码复核换取提权令牌）。
  - 渠道（guardrail）与模型别名（model group）CRUD 全链路支持 `zdrCapable`/`noTrainingCapable`/`zdrOverride`
    字段的读写（`console-provider-store.ts`、`console-model-alias-store.ts`、`config.ts`）。
  - 新增单元测试覆盖：ZDR 默认开启、四级作用域「最严格优先」解析、日志/持久化内容剥离、
    ZDR 生效时的渠道路由过滤（`test/zdr-settings.test.ts`、`test/zdr-log-redaction.test.ts`、
    `test/zdr-provider-filter.test.ts`）。
  - Console 前端（`console/ai-proxy-dashboard`）设置页新增「隐私 / ZDR」区块：读取/切换全局 ZDR 开关
    （`fetchZdrSettings`/`updateZdrSettings`），关闭前弹出二次确认对话框，确认后弹出密码复核对话框
    （`reauthForZdr` 换取一次性提权令牌后再提交关闭），成功/失败均有 Alert 反馈；沿用现有
    shadcn/ui 风格（`Dialog`、`Switch`、`Alert`），并补充中英文 i18n 文案。
