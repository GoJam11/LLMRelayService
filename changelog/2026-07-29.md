# 2026-07-29

### 新增

- **控制台完整英文（en-US）i18n 支持**：接入 `i18next-browser-languagedetector`，自动检测浏览器/系统语言，
  优先读取 `localStorage`（key: `lrs-console-lang`），检测不到时回退中文（zh），English 可在导航栏一键切换
  （`nav-bar.tsx` 新增语言切换按钮）。补全 `api-docs-page`、`routes-page`、`providers-page` 等页面遗留的
  硬编码中文文案，抽取为 i18n key 并补上英文翻译；模块级常量（如 API 文档的 `ENDPOINTS`/请求体示例）
  改造成接受 `t` 函数参数的工厂函数，随语言切换实时更新。
  日期时间与数字格式化（`formatTime`、`formatCount`、`keys-page` 的 `formatDateTime`、请求列表排序的
  `localeCompare`）改为使用当前 `i18n.language` 而非硬编码 `zh-CN`，实现本地化的日期/数字格式。
  代码注释保留原有中文，逐条补充英文翻译，不删除中文内容。

### 修复

- **Docker/CI `bun install --frozen-lockfile` 失败**：重新生成并提交与当前 `package.json` 一致的 `bun.lock`，
  修复镜像构建阶段 lockfile 漂移导致的 `lockfile had changes, but lockfile is frozen` 错误。
